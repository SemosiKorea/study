시작하기 · 회사는 여러 개, 경제실체는 하나

갑이 을을 지배하면 연결재무제표에서는 두 회사를 하나의 경제실체로 본다. 을의 자산·부채·손익을 100% 합치고 그룹 내부의 투자·자본·채권채무·거래를 제거한다. 외부 주주에게 속하는 자본과 손익은 비지배지분(NCI) 및 비지배주주 귀속손익으로 구분한다. 지분율 80%라는 이유로 자산·부채를 80%만 합치지 않는다.

지배력의 세 요소: 피투자자에 대한 힘, 변동이익에 대한 노출 또는 권리, 그 힘으로 이익에 영향을 미치는 능력. 의결권 과반수는 중요한 단서지만 지배력 판단의 절대조건은 아니다. 보호권만으로 지배력이 생기지 않는다. 아래 사례는 일반적인 지배기업으로 연결 면제·투자기업 예외가 없고, 회계정책·보고기간이 일치하며 보통주 외 잠재적 의결권·우선주가 없다고 가정한다.

계산순서: 무엇을 묻는지 확인 → 지배력 취득·상실 시점 → 취득일 순자산 공정가치·비지배지분·영업권 → 취득 후 손익만 합산 → 공정가치 차이 실현·내부거래 제거 → 전체 연결순이익 → 지배·비지배 귀속 → 배당·OCI 포함 기말 비지배지분 → 차대변·기말 잔액 검산.

분개 읽는 법: 실제 장부 분개와 연결정산표 조정을 구분한다. 연결조정은 양사의 실제 장부에 전기하지 않는다. 따라서 다음 해 연결에서도 전기의 누적 조정을 다시 반영한다. 내부채권·채무는 서로 제거하며, 제거 후 남는 외부 현금 이동·당기손익·장부금액을 따로 본다. 자산 손상을 나타내는 내부거래 손실까지 기계적으로 지우지는 않는다.

사례 01은 완성예제로 따라 읽고, 사례 02는 이익률과 조정순이익을 먼저 계산해 보세요. 사례 03은 다음 연도 실현액을 예상한 뒤 분개를 펼치고, 사례 04는 지배력 유지 여부부터 독립적으로 판단하세요. 사례 02만 실제 기출이며 나머지는 자체 제작입니다. 자체 제작의 난도 확장은 출제 사실이나 출제 확률을 뜻하지 않습니다.

자체 제작 · 기본 복합CASE 01

80%를 샀는데 자산·부채는 왜 100% 합칠까?

지배하는 회사를 한 경제실체로 보므로 자산과 부채를 전액 합친다. 대신 종속기업에 대한 외부 주주의 몫을 비지배지분으로 구분한다. 투자주식과 종속기업 자본은 중복이므로 연결에서 없앤다.

자체 제작문제 · 법인세효과 제외 · 단위 원

갑은 X1년 초 을의 보통주 80%를 현금 980,000원에 취득하여 지배력을 얻었다. 을의 취득일 장부자본은 자본금 600,000원과 이익잉여금 400,000원이다. 장부금액보다 공정가치가 높은 항목은 재고자산 50,000원과 건물 150,000원뿐이다. 취득일 재고의 60%는 X1년에 외부로 팔렸고 건물의 잔존내용연수는 5년·잔존가치 0·정액법이다. 비지배지분은 취득일 공정가치 270,000원으로 측정한다. X1년 갑의 별도 순이익은 500,000원으로 을의 배당수익 40,000원을 포함한다. 을의 순이익은 200,000원, OCI는 40,000원, 보통주 전체 현금배당은 50,000원이며 그해 확정·지급됐다. 갑은 별도재무제표에서 투자주식을 원가법으로 처리한다. 법인세·영업권 손상·다른 내부거래는 없다. 연결당기순이익 / 그중 지배기업 소유주 귀속분 / 기말 비지배지분은?

① 600,000 / 572,000 / 296,000
② 572,000 / 572,000 / 296,000
③ 640,000 / 612,000 / 296,000
④ 600,000 / 572,000 / 266,000
⑤ 600,000 / 560,000 / 308,000
판단 순서 · 기간별 분개 · 기말 잔액 검산

갑의 실제 장부 · 투자주식 취득

갑은 을의 건물·재고를 자기 장부에 직접 기록하지 않고 종속기업투자주식을 기록한다. 다음 단계부터는 양사 장부를 합산한 뒤 연결재무제표를 위한 조정이다.

차변종속기업투자주식980,000
대변현금980,000

취득일 순자산과 영업권

순자산 공정가치 = 600,000+400,000+50,000+150,000 = 1,200,000원. 영업권 = 이전대가 980,000+비지배지분 공정가치 270,000−1,200,000 = 50,000원. 비지배지분의 공정가치를 단순히 이전대가의 20/80로 역산하지 않는다.

취득일 연결조정 · 투자와 자본 제거

종속기업의 취득 전 자본을 전액 제거하고, 투자주식도 제거한다. 공정가치 증가분과 영업권을 반영하며 외부 주주 몫 270,000원을 비지배지분으로 표시한다. 이 분개를 각 회사의 실제 장부에 전기하지 않는다.

차변을 자본금600,000을 취득일 이익잉여금400,000재고자산50,000건물150,000영업권50,000
대변종속기업투자주식980,000비지배지분270,000

X1년 · 취득일 재고 차이의 실현

취득일에 올린 재고 가치 중 팔린 부분 50,000×60% = 30,000원이 연결실체의 추가 매출원가다. 미판매분 20,000원은 기말 재고에 남는다.

차변매출원가30,000
대변재고자산30,000

X1년 · 건물의 추가 감가상각

추가 상각 = 150,000÷5 = 30,000원. 을의 이익을 200,000−30,000−30,000 = 140,000원으로 조정한 후 귀속을 나눈다.

차변감가상각비30,000
대변감가상각누계액30,000

배당 연결조정 · 내부 수익 제거와 외부 분배

갑의 배당수익 40,000원은 내부 수익이라 제거한다. 외부 비지배주주에게 지급한 10,000원은 비지배지분 감소다. 대변의 을 배당은 을의 이익잉여금 감소액을 되돌리는 연결조정이다.

차변배당수익40,000비지배지분10,000
대변을 배당에 따른 이익잉여금 감소액50,000

연결순이익과 귀속

전체 연결순이익 = 갑 500,000−내부배당 40,000+을 조정이익 140,000 = 600,000원. 비지배주주 귀속 = 140,000×20% = 28,000원. 지배기업 소유주 귀속 = 500,000−40,000+140,000×80% = 572,000원. 572,000+28,000 = 600,000원이다.

기말 비지배지분 · 순이익 외 변동도 포함

270,000+순이익 지분 28,000+OCI 지분 40,000×20%−배당 10,000 = 296,000원. 연결 OCI 40,000원은 지배주주 32,000원·비지배주주 8,000원으로 나눈다. OCI를 연결당기순이익에 더하지 않는다.

독립 검산과 측정방법 비교

을 기말 장부순자산은 1,000,000+200,000+40,000−50,000 = 1,190,000원. 미실현 재고차이 20,000과 건물 잔여차이 120,000을 더한 1,330,000원의 20%는 266,000원이다. 여기에 취득일 비지배지분에 포함된 영업권 270,000−1,200,000×20% = 30,000원을 더하면 296,000원. 비지배지분을 순자산 비례액으로 측정하는 별도 조건이라면 취득일 비지배지분 240,000·영업권 20,000·기말 비지배지분 266,000원이 된다. 손상이 없는 본 사례의 순이익 귀속은 두 방법에서 같다.

정답과 검산

①. ②는 지배주주 귀속분을 연결순이익 전체로 착각했다. ③은 갑의 내부 배당수익을 제거하지 않았다. ④는 공정가치 측정 조건을 무시하고 비례액 방식을 사용했다. ⑤는 취득일 공정가치 차이의 실현을 비지배주주 손익에 반영하지 않아 40,000원을 비지배순이익으로 계산했다.

30초 회상 · 비지배지분은 지배기업이 갚아야 할 부채일까? 을의 취득 전 이익잉여금은 연결당기이익일까?

비지배지분은 연결자본 안의 외부 주주 몫이다. 취득 전 이익잉여금은 투자와 제거할 취득일 자본이며 취득 후 연결당기이익이 아니다.

실제 기출 · 2023년 A형 14번CASE 02

원가에 25%를 더했다면 재고의 25%가 이익일까?

재고 금액이 원가 기준인지 판매가격 기준인지부터 확인한다. 연결에서는 내부이익 전액을 제거하지만, 종속기업이 판매한 이익의 조정은 지배주주와 비지배주주가 나눠 부담한다.

실제 기출 요약 · 원문 선지 유지 · 단위 원

세무는 X1년 초 한국의 보통주 80%를 900,000원에 취득하여 지배력을 얻었다. 취득일 한국의 순자산 장부금액은 1,000,000원이며 건물 외 자산·부채의 장부금액과 공정가치는 같다. 건물 장부금액은 500,000원, 공정가치는 600,000원이고 잔존내용연수 10년·잔존가치 0·정액법이다. 한국은 원가에 25%의 이익을 더해 세무에 상품을 판매하며, 세무의 기말 재고에 이 상품 50,000원이 포함됐다. X1년 별도 순이익은 세무 250,000원·한국 120,000원이다. 세무는 투자주식을 원가법으로 처리하고, 비지배지분은 식별 가능 순자산 공정가치의 비례액으로 측정한다. 연결포괄손익계산서의 지배기업 소유주 귀속 당기순이익은? 원문 조건과 선지를 유지하여 요약했다.

① 328,000
② 330,000
③ 338,000
④ 346,000
⑤ 350,000
판단 순서 · 기간별 분개 · 기말 잔액 검산

취득일 연결조정 · 전체 금액으로 제거

건물 공정가치 차이 100,000원을 반영한 순자산은 1,100,000원이다. 비지배지분 220,000원, 영업권 900,000−1,100,000×80% = 20,000원. 원문에 자본금·이익잉여금의 구분이 없어 취득일 장부자본 합계로 표시한다.

차변한국 취득일 장부자본1,000,000건물100,000영업권20,000
대변종속기업투자주식900,000비지배지분220,000

건물 추가 상각 · 지분율을 곱하기 전

공정가치 차이 100,000÷10년 = 10,000원을 연결 감가상각비로 추가한다. 전체 연결 조정액은 8,000원이 아니라 10,000원이다.

차변감가상각비10,000
대변감가상각누계액10,000

원가가산율을 매출이익률로 바꾸기

판매가 = 원가×1.25이므로 판매가 중 이익비율 = 0.25/1.25 = 20%이다. 재고 50,000원 안의 내부이익은 50,000×20% = 10,000원이다. 50,000×25% = 12,500원으로 계산하면 안 된다.

상향거래 미실현이익 제거

한국→세무의 상향거래다. 재고에 남은 이익 10,000원을 전액 제거하여 연결재고를 줄이고 매출원가를 늘린다. 연간 내부매출 총액은 원문에 없어 그 제거분개 금액을 임의로 만들지 않는다. 내부매출 총액을 T라고 하면 차변 매출 T / 대변 매출원가 T로 제거하며 그 자체는 순이익을 바꾸지 않는다.

차변매출원가10,000
대변재고자산10,000

한국 조정이익과 귀속

한국 조정이익 = 120,000−건물 추가 상각 10,000−재고 미실현 10,000 = 100,000원. 지배기업 소유주 귀속 = 250,000+100,000×80% = 330,000원. 비지배주주 귀속은 20,000원이다. 원문에 없는 배당·세금·다른 거래를 추가하지 않는다.

전체 연결순이익으로 검산

전체 연결순이익 = 250,000+120,000−10,000−10,000 = 350,000원. 지배주주 330,000+비지배주주 20,000 = 350,000원으로 일치한다. 내부이익 제거액 10,000원 중 지배주주 부담 8,000원과 비지배주주 부담 2,000원을 합하면 전액 제거된다.

기존 비지배지분 20% 중 절반인 10%포인트를 샀으므로 비지배지분 감소액 = 230,000×10/20 = 115,000원이다. 지급액 120,000원과의 차이 5,000원은 지배주주 자본 감소다. 아래는 이미 기록한 실제 매입분개에 추가하는 연결조정이므로 대변은 현금이 아니라 투자주식이다. 이 차이로 새 영업권이나 비용을 만들지 않는다.

차변비지배지분115,000지배기업 소유주 자본5,000
대변종속기업투자주식120,000

X2년 말 → X3년 처분 직전

X2년 말 을 순자산 = 1,150,000+200,000−50,000 = 1,300,000원. 비지배지분 = 115,000+200,000×10%−50,000×10% = 130,000원. X3년 6월 말 을 순자산 = 1,300,000+60,000−20,000 = 1,340,000원. 비지배지분 = 130,000+60,000×10%−20,000×10% = 134,000원. 상반기는 아직 종속기업이므로 을의 손익을 전액 연결한 뒤 90:10으로 귀속한다.

지배력 상실 · 먼저 무엇을 없앨까?

매각한 70%만 제거하는 것이 아니다. 을의 자산·부채와 영업권을 전부 연결에서 제거하고 기존 비지배지분도 없앤다. 받은 현금과 남은 20%의 공정가치를 인식한다. 지배력 상실손익 = 현금 1,120,000+잔존지분 공정가치 320,000+제거할 비지배지분 134,000−순자산 1,340,000−영업권 100,000 = 이익 134,000원이다.

X3년 7월 · 연결재무제표 효과 요약

아래는 연결 기준 처분 효과를 한 번에 나타낸 요약이며 별도 장부의 처분분개에 그대로 더하는 조정분개가 아니다. 실제 연결정산표에서는 별도 처분손익을 제거한 후 이 효과를 만든다. ‘을 순자산’은 개별 자산 제거와 부채 제거의 순액 표시다. 영업권 제거와 비지배지분 제거를 모두 포함한다.

차변현금1,120,000관계기업투자320,000비지배지분134,000
대변을 순자산1,340,000영업권100,000지배력 상실이익134,000

왜 잔존지분을 다시 측정할까?

지배력 상실일의 공정가치 320,000원이 새 관계기업 투자의 최초 원가가 된다. 식별 가능 순자산 지분 1,340,000×20% = 268,000원과 차이 52,000원은 새 관계기업투자에 포함된 영업권이다. 기존 연결영업권 100,000원의 20%를 그대로 남기는 방식이 아니다. 본 사례에 OCI는 없지만 실제 문제에 있으면 해당 항목을 직접 처분했을 때의 기준에 따라 재분류 또는 이익잉여금 대체를 별도로 판단한다.

X3년 하반기 · 지분법이익

관계기업 전환 후 이익만 대상으로 100,000×20% = 20,000원을 인식한다. 전환일 식별 가능 순자산의 공정가치 차이가 없어 추가 상각은 없다. 투자에 포함된 영업권도 상각하지 않는다.

차변관계기업투자20,000
대변지분법이익20,000

X3년 하반기 · 배당은 회수

현금 20,000×20% = 4,000원을 받고 투자금액을 줄인다. 이미 인식한 지분법이익에 배당수익을 다시 더하지 않는다.

차변현금4,000
대변관계기업투자4,000

기말 검산 · 두 경로

관계기업투자 = 320,000+20,000−4,000 = 336,000원. 다른 경로: 을 기말 순자산 (1,340,000+100,000−20,000)×20%+새 투자에 포함된 영업권 52,000 = 336,000원. 추가 취득 시 5,000원은 자본 감소, 지배력 상실 시 134,000원은 당기손익, 처분 현금 1,120,000원은 대가이므로 서로 같은 금액이 아니다.

독립 변형 · 비지배지분도 0에서 손실 인식을 멈출까?

이 문단만 별도 조건이다. 최초 비지배지분 200,000원·지분율 20%에서 종속기업의 조정 후 손실이 1,200,000원 발생하고 배당·OCI·다른 조정이 없다면, 비지배지분은 200,000−1,200,000×20% = −40,000원이다. 다음 해 조정 후 이익 300,000원이 발생하면 −40,000+60,000 = 20,000원이다. 비지배지분이 음수가 되어도 손익을 배분한다. 관계기업 지분법의 손실 인식 한도와 혼동하지 않는다. 이 독립 변형은 본문 정답 계산에 섞지 않는다.

정답과 검산

①. ②는 지급액이 취득한 비지배지분 장부금액보다 크므로 자본이 감소한다는 방향을 뒤집었다. ③은 지배력 상실 때 제거할 영업권 100,000원을 빠뜨렸다. ④는 지배력을 상실했는데도 전부 자본거래로 처리했다. ⑤는 잔존투자의 최초 원가를 공정가치 320,000원이 아닌 순자산 지분 268,000원으로 시작해 268,000+20,000−4,000 = 284,000원으로 계산했다.

30초 회상 · 숫자 없이 말하기 · 일부 매각 뒤 지배력을 유지하는 경우와 유의적인 영향력만 남는 경우의 결정적 차이는?

지배력 유지 시 계속 전액 연결하고 지배·비지배주주 사이의 자본거래로 처리한다. 지배력 상실 시 종속기업 전체와 영업권·비지배지분을 제거하고 잔존투자를 공정가치로 인식하며 처분손익을 계산한 뒤, 영향력이 있으면 그 시점부터 지분법을 적용한다.

근거 · 출처와 검토 범위

교재 「객관식 재무회계.pdf」 제24장 연결회계, PDF 658~667쪽을 확인했다. PDF 659~661쪽은 비지배지분 측정·취득일 차이와 연결순이익, 662~663쪽은 내부거래 제거와 귀속, 664~667쪽은 비지배지분·영업권·음의 비지배지분 논점이다. 쪽수는 인쇄면이 아닌 PDF 뷰어 기준이다.
